「知遇」智能客服是 Anker 首届黑客松「赛道四 · 智能服务：真正听懂，真正解决」的参赛项目。它承接用户的售后求助：理解情绪化与歧义表达、确认产品、检索知识库排障、必要时创建人工工单并交接。

完整部署中的真实实现

  • 知识库问答：硅基流动 BGE-M3 向量检索 + Milvus，MySQL 保存权威原文
  • 创建工单：真实写入本地 MySQL，人工工单台可查看交接摘要

模拟与本页面的边界

  • 订单、商品、物流数据为随机模拟，不代表真实业务信息
  • 本页面为纯静态演示站：对话是预录回放，不连接任何后端
  • 本页面不会创建真实工单、不收集任何输入
  • 完整系统仅面向本地单用户演示，无鉴权，不可直接公开部署

前端样式与消息结构直接复用自项目真实代码（app/static/chat.css / chat.js），回放脚本依据仓库 README 的演示流程编写。
